# The Alpha Family

*Specialist AI assistants for data and analytics*

The Alpha Family is a Volan9 Lab research project exploring how AI assistants can help data and analytics practitioners solve everyday problems, from bringing in a new data source to investigating a number in a report.

## Meet the assistants

| Assistant | Role | When to use it |
| --- | --- | --- |
| **Alpha** | Coordinator | Clarify what you need, find the right specialist, or bring together findings from several specialists. |
| **Rio** | Data ingestion | Bring in data from an API, database, or file, or investigate why a feed is missing. |
| **Newt** | Data harmonisation | Make raw data consistent and ready to use by standardising field names, types, and values. |
| **Argon** | Analytics | Explore data, define or check a metric, or turn findings into a report. |

Start with the specialist that fits your task, or start with Alpha if you're unsure where to begin.

## Project status

This repository introduces the concept and the initial assistant roles. Short instructions and practical examples will be added as the project develops.
